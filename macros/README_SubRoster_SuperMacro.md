# 替补队长名单回传超级宏

适用于原版 WoW 1.12／Turtle WoW 与本项目原版 `ADKP/` 的替补名单协议。
不是 Forever 版宏。替补队长只需已有 SuperMacro，不需要安装 ADKP 或 SuperWoW。
主记分员仍使用 ADKP，双方必须在同一公会。

## 设置方法

1. 在 SuperMacro 中新建一个宏，例如“替补名单”。
2. 将同目录 `ADKP_SubRoster_SuperMacro.lua` 的全部内容复制到右侧 **Extended Lua／扩展 Lua** 编辑区，点击 **Save Extend／保存扩展**。
3. 左侧普通宏正文填写下面一行，把引号中的名字换成主记分员实际的游戏角色名：

   ```text
   /script ADKP_SubRosterMacro_Start("主记分员名字")
   ```

4. 保存宏并拖到动作条，点击一次。聊天框应显示“已开启，只响应记分员：XXX”。
5. 主记分员在 ADKP 中将这个角色设为替补队长，点击“测试同步”，或输入 `/subteam refresh` 强制刷新。

Lua 文件是扩展代码，不要在文件内容前加 `/script`，也不要把整份文件粘到左侧普通宏正文。
文件小于 7000 字节，适合 SuperMacro 的扩展编辑区；该编辑区及保存方式见 [SuperMacro 官方说明](https://github.com/Monteo/SuperMacro/blob/master/readme.txt)。

## 活动时怎么使用

- 每次登录或 `/reload` 后点击一次启动宏，之后 ADKP 查询时会自动回传。
- 重复点击只会重新绑定记分员，不会重复创建监听或发送多份名单。
- 更换记分员时，修改左侧宏中的姓名，保存后重新点击。
- 支持团队、小队和单人状态；回传名单包含替补队长本人，是否给队长加分由主记分员端原有勾选决定。
- 主记分员端原有缓存仍生效，需要立即更新时使用 `/subteam refresh`。

查看运行状态：

```text
/script ADKP_SubRosterMacro_Status()
```

关闭自动响应：

```text
/script ADKP_SubRosterMacro_Stop()
```

## 通讯和完整性

- 仅响应指定角色通过公会插件频道发送、且明确查询自己的 `AMB_TBQQ` 请求。
- 沿用 `AMB_TBFS` 的“接收方#发送方#数据”格式，其他团的查询不会触发回传。
- 一次采集完整名单后按消息字节上限拆包，间隔 0.15 秒发送，末尾携带总人数；主记分员端沿用人数核对逻辑。
- 名单读取不完整时最多尝试三次，仍不完整就报告错误，不发送成功完成标记。
- 没有请求时不执行轮询。这个宏只回传当前成员姓名、职业和人数，不保存或同步 DKP 账本。

## 排查

- **启动后没有响应：**先检查宏中的记分员姓名、ADKP 中的替补队长姓名以及双方公会是否一致。
- **公会名册尚未加载：**主记分员先打开公会名单，再输入 `/subteam refresh`。原插件可能在尚未识别同公会时改走密语，本宏只监听公会插件消息。
- **提示尚未启动：**重新点击启动宏。重新登录和重载会清除之前的运行状态。
- **提示已安装 ADKP：**该角色直接使用 ADKP 的名单响应即可，宏会拒绝重复启动。
- **提示发送失败或名单不完整：**等队伍名单稳定后，再由主记分员 `/subteam refresh`。
- **不同公会：**本版宏不响应普通密语请求，不能用于跨公会回传。

本宏不依赖 ADKP 自身函数；主记分员端无需安装额外组件或修改配置文件。
