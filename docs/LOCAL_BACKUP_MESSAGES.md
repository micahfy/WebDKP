# 新版本地备份与登录恢复提示

聊天提示统一带前缀 `[本地备份]`；同步模块的相关提示带 `[数据同步]`。花括号表示运行时内容。

| 提示 | 出现时机 |
| --- | --- |
| 检测到DKP记录异常，是否恢复自动备份的数据 | 登录发现本地有效恢复候选；确认按钮为“是 / 否” |
| 团队：{团队名称} | 团队选择信息也丢失时，补充在上述弹窗下方 |
| 已取消恢复，可继续记分；自动备份和数据同步发布已暂停。 | 拒绝本地或对端恢复 |
| 记录存在异常，自动备份已暂停 | 状态栏持续提示；主动请求恢复期间显示恢复进度 |
| 记录存在异常，可继续记分；自动备份和同步发布已暂停 | 内部同步状态、诊断输出 |
| 已完整恢复当前团队的本地备份数据。 | 本地全量替换成功 |
| 备份需要 SuperWoW 的文件读写功能。 | 手动备份时没有文件 API |
| 正在检查恢复或记录存在异常，暂不更新备份。 | 检查中或异常保护期间手动备份 |
| 备份失败，旧备份保留：{错误详情} | 快照生成、结构或大小校验失败 |
| 备份写入校验失败，旧备份保留。 | D 文件写入、读回或解码校验失败 |
| 团队备份索引写入失败，旧备份保留。 | 团队目录写入校验失败 |
| 备份指针写入失败，旧备份仍可恢复。 | P 指针发布失败 |
| 数据已完整备份到：{文件名} | 手动备份成功 |
| 数据发生变动，已自动备份。 | 自动备份成功；十分钟内不重复提示 |
| 备份不完整、校验失败或团队不匹配，原数据保留。 | 全量恢复校验失败 |
| 未找到当前团队有效的新版完整备份。 | 恢复最新数据没有可用来源 |
| 仅支持新版完整备份，原数据未改变。 | 导入旧格式、坏文件或错误文件 |
| 请输入版本文件名。 | 调用指定版本导入时文件名为空 |
| 请先输入要导入的版本文件名。 | 点击“导入”时输入框为空 |
| 当前团队已改变，请重新选择备份。 | 指定版本确认窗口打开后切换了团队 |
| 确定从版本 [{文件名}] 恢复吗？\n将完整替换当前团队业务数据并恢复记分设置。 | 指定版本导入确认窗口 |
| 记录版本检查失败，旧备份保留：{错误详情} | 自动更新本地业务版本失败 |
| 记录存在异常，请恢复数据或导入网站数据后再开启同步。 | 异常保护期间尝试开启同步 |
| 替补副本不能自行替换数据，请由主团队长同步。 | 尝试用非授权来源替换正在接收的副本 |
| 本机日期早于数据版本，请校正日期后再记分。 | 本机日期倒退时尝试修改 |
| 本机日期早于数据版本，请校正日期后再导入。 | 本机日期倒退时尝试网站导入 |

`完整备份校验失败` 和 `本机日期早于备份版本` 是内部异常详情，可能包含在“备份失败”或“记录版本检查失败”中。对端恢复、整库接受和其他同步提示继续参考 [同步提示清单](DATA_SYNC_MESSAGES.md)。
