# Boss 击杀确认规则

适用 WoW 1.12 / Lua 5.0。名单以用户 2026-10-17 确认的版本为准，共 101 个可选首领项；BigWigs 目录仅作为资料参考，不是运行依赖。

## 名单与完成条件

普通首领共 95 项：收到匹配名称的死亡消息后记录击杀，等待记分员本人脱战，再弹窗／进入全自动加分流程。自定义首领沿用普通死亡规则。

以下 6 场特殊首领均先满足完成条件，再等待记分员本人脱战。普通、特殊、自定义首领共用整场战斗最多一次加分的限制。

| 名单显示 | 完成条件 |
| --- | --- |
| 双子傀儡 | 斯摩达利斯（Smoldaris）或巴萨尔萨（Basalthar）任一死亡 |
| 管理者埃克索图斯 | 本次挑战累计 4 名烈焰行者精英、4 名烈焰行者医师死亡；只在熔火之心累计 |
| 双子皇帝 | 维克尼拉斯大帝或维克洛尔大帝任一死亡 |
| 安其拉三宝 | 维姆、克里勋爵、亚尔基公主全部死亡，顺序不限 |
| 天启四骑士 | 大领主莫格莱尼、库尔塔兹领主、女公爵布劳缪克丝、瑟里耶克爵士全部死亡，顺序不限 |
| 破碎者鲁普图兰 | 在对应区域，收到该首领自己的胜利喊话，包含中文“化为尘土”或英文 `Perished... To dust` |

组合成员不再单独出现在内置名单中，其名称映射到同一首领的开关、分值、弹窗、记录和团队通报。重复成员死亡不会重复完成；管理者的同名随从按数量累计，不按名字去重。

移除内置的维克多·奈法里奥斯领主、费尔根、斯塔拉格；国王保留一个项目；索尔纽斯两个英文名称映射到同一项。中文名称按用户清单修正，历史名称只保留为匹配与设置迁移别名。

**用户明确选择：塞卡尔、斯克拉姆、科罗恩仍按普通死亡处理。** 不额外排除塞卡尔第一阶段假死或斯克拉姆分身，也不通过科罗恩转为非敌对判断完成。因此这些机制可能提前触发或缺少触发；此处保留用户指定规则，不自动改为其他判定。

## 中英文与设置迁移

- 使用客户端原生 `UNITDIESOTHER` 格式，并兼容中英文死亡／击杀句式；英文 NPC 名忽略大小写。
- 名单、弹窗和记录根据客户端语言选择中文或英文首领名称，悬停可查看另一语言名称、组合成员和完成规则。提示正文宽度固定并换行。
- 新旧中文名、英文别名和组合成员共用同一套设置。保留已有的组合名称分值；尚无组合分值时，只有成员的生效分值一致才继承。
- 成员旧分值不一致时，相关字段使用统一默认分值并聊天提示重新设置；冲突原值保存在 `WebDKP_Options.BossEncounterMergeConflicts`。其他团队／玩家 DKP 和历史日志不改写。
- 若任一旧成员曾被禁用，迁移后组合默认为禁用，管理员可在名单中统一开启。

## 同场合并、连续战斗与重试

- 同场战斗中，普通死亡、完成组合、胜利喊话都只登记候选；脱战后只选择最后满足完成条件的首领，不累加其他首领的分值。未完成的组合不参与选择。
- 候选满足条件时记录其主团／替补分值、模式和 DKP 团队；使用最终候选的名称和分值。结算后收到其他死亡或喊话也不会追加；关闭弹窗或异步等待期间仍保留本场已结算标记。
- 仍以记分员本人脱战作为结算时机。若此时其他团员仍在战斗，该场后续击杀不会再次结算；个人重新进战也不会重新获得加分次数。整个存活团队脱战后再次进战才开始新一场，重置本场次数和计数。未观察到团队脱战的连续拉怪归入同一场。
- 不同场战斗分别保留奖励快照。前一个弹窗未处理或前一次替补名单查询未结束时，后续战斗排队，避免覆盖全局名称或同步回调；新弹窗和全自动流程均等待记分员脱战才启动。
- 点击确认只执行当前队列项；关闭弹窗跳过当前项。下一弹窗至少隔一个刷新周期打开，防止连点确认到下一项。
- 全自动和弹窗共用原有主团／替补加分及团队通报流程；自动记录仍关联实际 DKP 日志。
- 切换 DKP 团队时不将待处理击杀写入新团队；异步同步期间发生切换则暂停该次加分，切回原团队后通过弹窗确认。
- 组合未完成时，仅记分员个人脱战或死亡不清空进度。整个存活团队稳定脱战 3 秒后清空未完成进度，防止下次挑战沿用上次的部分击杀；即使不足 3 秒就开始新一场，也不沿用旧计数。尚未处理的奖励项保留。
- 关闭功能／插件或离开队伍后，刷新时清除未执行的队列，不在重新开启时补发旧击杀。

## 验证与边界

```text
python tests/run_boss_encounter_tests.py --lua <Lua 5.0 解释器>
python tests/run_backup_check_tests.py --lua <Lua 5.0 解释器>
```

测试使用真实名单、确认模块、主文件设置／弹窗／异步加分入口、DKP 日志和自动记录逻辑，模拟客户端事件与名单同步。覆盖全部普通首领的中英文及两种模式、同场多首领及普通／特殊／喊话混合最多一次、最后候选分值快照、个人脱战再进战、新一场重置、四骑士 24 种顺序、三宝 6 种顺序、共享血量去重、管理者 4+4、喊话来源与区域、团灭重试、不同战斗的弹窗队列、分值迁移和切团保护。

需要游戏内验证实际死亡消息范围、中文喊话和区域名、原生窗口表现及替补名单通讯。仅根据本客户端实际收到的事件确认，不通过超时推算缺失死亡；重载界面／重新登录不会保留未完成挑战的计数。管理者使用唯一的标准死亡消息通道计数，不额外叠加 SuperWoW 或 BigWigs 的死亡通知。
