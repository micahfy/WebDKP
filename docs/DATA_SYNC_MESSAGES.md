# 数据同步游戏内提示词清单

依据当前工作区的 `ADKPSYN2` 实现整理。保留现有文案，不改写措辞。`{玩家}`、`{日期}`、`{修订号}`、`{错误详情}` 等表示运行时内容，日期/版本示例为 `2026-10-14/3`。

新整库同步的聊天提示和诊断输出统一在正文前加 `[数据同步] `，经 ADKP_Print 显示为黄色；下面的 C、D 表省略这个共同前缀。状态栏、按钮和弹窗不加此前缀。

新整库同步共整理：25 条常规聊天模板、35 种状态文字、3 类确认弹窗、10 种诊断输出模板，以及按钮、悬停和状态组合字段。旧替补名单同步及关联的网站导入/插件总开关另列在末尾，不能将旧“同步测试成功”当成新整库同步完成。

### 状态行组合格式

- A：`替补：{玩家} · {状态文字} · 文件已保存` 或 `替补：{玩家} · {状态文字} · 文件待保存`。
- B：`主团：{玩家} · {状态文字} · 文件已保存` 或 `主团：{玩家} · {状态文字} · 文件待保存`。
- 没有启用活动链接时，只显示状态文字；不加角色前缀和文件保存后缀。
- “文件已保存 / 文件待保存”表示独立本机完整快照的写入状态，不表示对端已经同步成功。

## 3. 确认弹窗

以下三类共用按钮“接受 / 取消”。保留实际换行。

### P01：B 接受整库同步

```text
玩家 {玩家} 申请数据同步。
将替换原同步对象：{原对象}
团队：{团队名称}
版本：{日期}/{修订号}
接受后将替换当前业务数据，并自动绑定主团队长。
```

“将替换原同步对象”这一行仅在已有启用的同步对象时出现；没有旧对象则省略。团队名称不存在时显示 `DKP`。

### P02：从本机完整快照恢复

```text
尚未收到有效对端回复。是否从本机完整快照恢复？
版本：{日期}/{修订号}
包含全部业务数据；可能落后于离线对端，连通后会继续核对。
```

### P03：从对端恢复完整数据

```text
是否从{身份标签}{玩家}那里恢复完整数据？
团队：{团队名称}
版本：{日期}/{修订号}
```

身份标签的实际文案及尾部空格：

- 已有链接，恢复主团身份：`替补队长 `。
- 已有链接，恢复接收身份：`主团队长 `。
- 没有活动链接：`玩家 `。

例如没有保留下来的活动链接时会写“是否从玩家 xxxx那里恢复完整数据？”，不会固定写“替补队长”。

## 5. /adkpsync 诊断输出

手动执行 `/adkpsync` 时发送到聊天框，均带 `[数据同步] ` 前缀。


| 编号 | 原文 / 动态模板 | 触发条件或说明 |
| --- | --- | --- |
| D01 | 协议 ADKPSYN2；初始化={true/false}；公会={公会名/无}；插件={已禁用/已启用} | 协议和客户端环境 |
| D02 | 身份={none/master/slave}；同步={true/false}；对象={玩家/无}；状态={当前状态/未开启} | 身份、链接及状态 |
| D03 | 发送分片={数量}；收到公会协议包={数量} | 收发计数 |
| D04 | 最近完整消息={消息类型}；来自={玩家} | 有完整消息时显示 |
| D05 | 累计发送字节={数量}；补发分片={数量}；限速=500字节/秒 | 累计发送统计 |
| D06 | 最近业务传输={FULL/PATCH}；原始={字节}；编码后={字节}；分片={数量}；编码={E/B/Z}；补发={数量} | 最近业务传输存在时显示 |
| D07 | 最近整库传输=FULL；原始={字节}；编码后={字节}；分片={数量}；编码={E/B/Z}；补发={数量} | 最近整库与最近业务传输不是同一笔时额外显示 |
| D08 | 发送耗时={秒数}秒；含包头发送={字节}字节 | 分片发送完成；可能分别为最近业务/整库各显示一次 |
| D09 | 业务确认耗时={秒数}秒 | 已有业务确认时间；可能分别显示两次 |
| D10 | 最近发送错误（完整）：{错误详情} | 本次会话曾发生发送错误时显示 |



- 身份值直接显示英文：`none / master / slave`；布尔值直接显示 `true / false`。
- 消息类型可能为 `DISCOVER / SUMMARY / OFFER / OFFER_REQUEST / OFFER_SEEN / ACCEPT / REJECT / CATCHUP / GET / FULL / PATCH / DONE / CANCEL`。
- `E / B / Z` 分别表示转义、Base64、压缩后 Base64。
- 秒数保留一位小数。“最近发送错误”可包含客户端、其他插件或 Lua 文件路径与行号，内容无法穷举。

### 旧帮助页面

标题：`替补团数据同步`。

- 填写替补队长后，替补队长在线且安装了本插件的情况下，会自动在加分时获取最新的替补团数据。
- 同工会：通过插件频道自动同步替补团队数据。
- 跨工会：通过密语自动同步替补团队数据。
- 替补队长加分：勾选后给主团加分时一并把替补队长计入奖励名单。

帮助概览另有：`2. 替补团队数据同步：同工会走插件频道同步，跨工会走密语同步。`

## 7. 整库重置和总开关的共享提示

这部分在同步开启时与流程有关，但并非新通讯模块专用文案。

- 网站导入确认：`注意：历史数据将被全部清空并替换成导入数据！！`，按钮“确定 / 取消”。
- 网站导入完成聊天：`已导入 {数量} 条初始分。`
- 插件总开关关闭聊天：`ADKP 已禁用：击杀弹窗/查分回复/替补同步/悬浮窗已停止（右键小地图图标重新开启）`。
- 插件总开关打开聊天：`ADKP 已启用`。
