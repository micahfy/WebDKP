# 登录备份检查（CSV 版本）

适用于当前 `main` 的 WoW 1.12 / Lua 5.0 插件。仅使用 SuperWoW 本地文件；保留已有 CSV 和合并活动日志的恢复方式。

## 登录流程

- `PLAYER_LOGIN` 后等待初始化，调用 `ADKP_RestoreData(true)` 进行一次只读检查。在检查及确认期间暂停备份写入。
- 登录检查与“恢复最新数据”共用 `ADKP_FindLatestBackup`。查找当前角色、服务器、DKP 团队的最新有效备份；优先搜索近 60 天，并支持登记日期的补查及团 1 旧指针文件。
- 即使 SavedVariables 登记仍在，也检查同一天更高的指针序号。最新 D 文件格式无效或不存在时，尝试较早的可用备份。
- 比较 `LatestBackup[角色标识][团队ID]` 中的 `Date / Counter / PointerFile / DataFile`。登记一致或没有有效文件时不弹窗；登记缺失或任意字段不一致时提示，不增加“备份较旧不恢复”的判断。
- 确认窗口文字：**检测到DKP数据差异，是否恢复最新备份数据**；按钮“确认 / 取消”。其他弹窗占用时保留候选并重试展示。
- 确认后调用同一个恢复入口，重新读取并验证已提示的文件，补齐日志、跳过重复记录。团队切换或候选文件变化时拒绝写入错误团队／变化后的文件。
- 恢复与大小号关系元数据处理全部成功后更新登记标记；所有日志已存在时也算成功。恢复不创建新 D/P 文件。
- 取消后不修改数据，本次登录不再次提示，允许继续记分；当前角色和团队的自动备份暂停状态保存在 `WebDKP_Options.BackupRecoveryPaused`，跨登录保留。下次登录仍检查一次。

## 自动备份与恢复入口

入口集中在主界面“设置”页的“数据与备份”分组，包括自动备份、恢复最新数据、手动备份和指定版本导入。

自动备份复选框保留勾选状态，暂停时旁边显示“自动备份（已暂停）”。成功执行“恢复最新数据”、手动备份，或明确导入网站初始数据后解除暂停。导入指定版本也复用日志恢复；选择最新版本时同步更新最新备份标记。

备份 D 文件和 P 指针均写入后读回验证文本一致性，成功才登记 `LatestBackup`。CSV 内容先做结构校验；写入失败保留原成功标记。若同一秒多次备份，在数据文件名末尾添加序号以避免覆盖旧 D 文件。

这不是全量数据库恢复：继续沿用旧版的日志补齐及大小号元数据处理，不改变为覆盖团队数据库。比较的是成功备份标记，不是最后一条 Boss／装备日志时间，也不是数据库内容校验值。
